LYRA プライバシーポリシー

LYRA(以下「本アプリ」)は個人開発のブラウザ完結型アプリケーションです。 本アプリを提供するバックエンドサーバーは存在せず、開発者が利用者のデータを収集・保存・ 閲覧することはありません。

取得する情報とその利用目的

  • Google Drive: 本アプリは Google Drive API の drive.file スコープ(本アプリが作成したファイルにのみアクセス可能な非機微スコープ)を使用します。 利用者が登録した文献・メモ・音声などは、利用者自身の Google Drive のマイドライブ直下の 「LYRA」フォルダに保存され、開発者を含む第三者はアクセスできません。
  • Gemini API: 利用者が登録した文献(PDF・画像・テキスト)は、内容の読解・ 構造化のため、ブラウザから直接 Google の Gemini API に送信されます。この処理は Google のプライバシーポリシーに従って扱われ、本アプリの開発者はこの通信内容を 取得・保存しません。

データの保存場所

OAuthクライアントIDおよびGemini APIキーは、利用者が使用するブラウザの localStorageにのみ保存され、外部のサーバーに送信されることはありません。

共有・公開について

本アプリは、登録された文献やその抜粋を外部へ共有・公開・エクスポートする機能を持ちません。
