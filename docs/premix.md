## PLANCK 段階1(2026-10-07)

- タスク: `docs/duo/task-premix-planck.md`。段階1だけを実装。フリー／タイムライン／チェーンと既存データはそのまま残す。モード統一・移行・書き出しは含めない。
- 共通の道具バー「プランク」で、アクティブなエリアへ440pxの視野を置く。エリアが無ければ作る。視野・マスク・照準・変身は承認済みモックをもとに `js/planck.js`、音とカード・エリアの統合は `js/screens/premix.js`。
- 保存: 新しい `type: 'planck'` が `folderId`、位置、`len`、`lanes[{id,mute,solo}]` を持つ。中の音は既存の `sound` に `planckId` / `plLane` / `plAt` を追加する。`scope.cards` の参照は変えず、カードDOMを隠す。音量・範囲・元の見た目・カードM/S・ループ・残響・MIDI参照は保持。中では段のM/Sだけを使い、外へ戻すとカードのM/Sに戻る。
- 長さ5ms〜60秒、1〜10段。60秒を超える範囲はその頭から60秒へ切り取り、落とす前と後に通知。上下は段、左右は時間。端は範囲、上の線は音量。最低3pxを描画と当たり判定に使う。Altで自由位置、矢印でグリッド／段、Alt矢印は1ms、Ctrl矢印は最後に選んだ端。
- 同じ段は重ならない。空き位置へ寄せ、空きが無ければ入れず理由を表示する。長さを縮める時も同じ段の範囲の合計より短くせず、右から寄せて収める。使用している段は消さない。
- 音は既存の `voiceAt()` → `stripOf()` → エリアのバス(残響の送りも既存経路) → `safeOut()`。単体は周のプレイヘッド、チェーンでは長さを持つ1つの駒、リンクでは外のカードと同時。長さ変更時には未来の予約を取り消し、現在の周で既に鳴った波形を覚え直す。別エリアへ動かす時は現在の音と予約もバスへ移し、待機エリアは無音。位置の変更・切り取りは次の発音、音量・段M/Sは現在の発音にも効く。
- ネビュラとPLANETESの位置はプランクの視野の中心。プランクのDelete／リジェクトでは中の音をカードへ戻す。ピン留めした波形を抱えるプランクはリジェクトから保護。隠した波形は矩形選択に入れず、もともとのASTR線は保存したまま描画を休む。
- 波形の描画は同じAudioBufferを使う。最初にmin/maxの階層を作り、以後は倍率に合わせて読む。細かい倍率だけ元のサンプルを読む。停止して何も変わらない視野は再描画しない。
- 確認: 模擬I/Oの確認ページで、Edgeの実ポインター9項目と数値検証、JS構文を確認。長さを再生中に35回変更した予約記録でも同一波形の重複は0件。保存ファイルの経路・JSON復元・画面再構築・内部音源MIDIも確認。**耳、スマホ、本物のDrive／実ファイルの権限、ページを閉じて開き直す確認は未実施**。詳細はタスクの実装・検証記録。
- **段階1の最終チェック後の手直し(2026-10-07、ユーザー回答に従う)**: プランクも平行四辺形のエリアで判定し、枠外では本体と中の音の `folderId` を `null` にして再生と予約を止め、バスから切り離す。戻して▶を押すと再び鳴る。エリアを広げて置いた時はステータスで通知する。
- プランク単体の先読みは、表のタブで0.15秒、`document.hidden` の間だけ1.5秒。予約した最後の周までを記録し、短い周が窓に複数入っても二重予約しない。長さ変更時の未来の予約の取り消しは保持。タイムラインの処理は変更しない。1秒間隔の模擬で、2秒のプランク3周・0.25秒のプランク16周を重複・抜けなしで確認。数値45項目とPlaywrightの実ポインター9項目が成功。**本物の裏タブでの長時間の実測・耳での確認は未実施**。

## プレミックスの基本とネビュラ

- **プレミックス(2026-09-27、ユーザー要望「『ランチャー』『ソウル』『アンサンブル』に続く4つ目のUI『プレミックス』を簡易的に実装」。
  ゆくゆくは本格的なシーケンサー・ミキサーに進化させる前提の簡易版)**: `js/screens/premix.js`、ルートは`#/premix`、入口はヘッダーの舞台タブの右隣。
  - フォルダカード: 道具バー「フォルダ」でPCのフォルダを選ぶ(File System Access API。Chrome/Edge)。中のオーディオを**ファイル名の順に最大10個**
    オーディオカードにする(「最大10個」は1フォルダあたりのオーディオの数と解釈した)。カードの大きさがそのまま**プレミックスエリア**
    (リサイズの上限はフォルダだけ2600px)。**最後に触ったエリア(フォルダカードとその見出しのボタン)がアクティブ**で(**オーディオカードを押しても・別のエリアへ落としても・カードの▶でも
    切り替えない**。2026-09-29、ユーザー要望「アクティブなエリアの再生中に別のエリアから音を取ってくると止まる。止まるのは他のエリアを触った時だけに」。
    待機中のエリアのカードを鳴らした時は、聞こえない理由をステータスに出す)、
    **鳴るのはアクティブなフォルダの音だけ**(他のフォルダは再生を止めずにバスの音量を0にする。戻すとそのまま聞こえる)。
    「▶ 全部」「■」「読み直す」(増えたファイルを足し、消えたファイルは「見つかりません」)
  - オーディオカード: 再生/停止・ループ(鳴らしながら切り替え可。外すと今の周の終わりで止まる)・音量・残響。何枚でも同時に鳴らし、
    鳴らしながらどれでも操作できる。音はカード → 音量 → フォルダのバス、残響はフォルダごとのConvolver(合成したインパルス応答)へ送る。
    フォルダをドラッグすると中のカードも一緒に動く(`js/canvas.js`の`onCardDragging`フック)
  - **エリア間の移動(同日、ユーザー要望「他フォルダのオーディオカードをアクティブプレミックスエリアに入れたら鳴らせるように」)**:
    オーディオカードを別のフォルダの枠の中に落とすと、そのエリアの一員になる(鳴っていれば止めずにバスをつなぎ替える。
    落とした先はアクティブにしない)。`folderId`=いるエリア(鳴る場所・一緒に動く枠)、`sourceFolderId`=ファイルの出どころ(読み込み・「読み直す」・
    1フォルダ10個の数え方。元のフォルダへ戻すと消える)。カードに「← 元のフォルダ名」、フォルダの見出しに「他のフォルダからn」。
    どの枠の中でもない所に落とすと今のエリアの中へ戻る。フォルダを外すと、そのフォルダのファイルのカードはどこにいても外れ、
    そのエリアに入れていた他のフォルダのカードは元のフォルダへ戻る
  - **音声はDriveに上げない**。フォルダのハンドルはIndexedDB(`lyra-local`の`handles`、キー`premix:<フォルダカードのid>`)、音はその場で
    ファイルから読む。Driveのデータ(`state.premix`)に残るのはカードの位置・大きさ・ファイル名・ループ/音量/残響とアクティブなフォルダだけ。
    ページを開き直すとブラウザの決まりでフォルダの読み取り許可が切れるので、フォルダカードの「アクセスを許可」を1回押す。別の端末では
    「フォルダを選び直す」。画面を離れると全部止める
  - **フリー/タイムライン(同日、ユーザー要望)**: フォルダカードごとに切り替える。フリー=上のとおり。タイムライン=エリアの左端が0秒で
    左から右へ時間が流れ、**エリアの幅全体が1ループ**(長さは見出しの「ループ n秒」、既定8秒。エリアを広げるとタイムラインが拡大される)。
    グリッド(0.25・1・4秒)と秒数、プレイヘッド。**カードの左端にプレイヘッドが触れた瞬間に鳴る**(カードのループは無視して1回、ループの
    終わりで切る)。発音はWeb Audioの時刻で0.15秒先まで予約(描画と別の30msのタイマーでも予約するので、描画が遅れてもずれない)。
    カードの位置は鳴り始めの時刻`s.tlStart`で持ち、0.25秒にそろえる。エリアの大きさ・長さを変えるとカードはその時刻の位置へ付いていく。
    カードの左端がループの中にあればよく、右側はエリアの外にはみ出してよい。カードの上辺の光る帯=実際の音の長さ(カードの幅とは無関係)。
    当初は「1秒=40px固定・エリアの幅=長さ」にしたが、短いループでエリアが細くなりカードが置けないため、今の形に変えた
  - **Shift+D でオーディオカードを複製**(編集ガイドのカード、なければ最後に触ったカード)。フリーは右下へ少しずらし、タイムラインは元の音が
    鳴り終わる時刻に置く(続けて押すと右へ並ぶ)。AudioBufferは共有。「1フォルダ10個」は読み込むファイルの数で、複製は数えない
  - **カード/スフィアと語彙メモ・切り取り(2026-09-29、ユーザー要望)**: 目指す先は「アンサンブルの**混合美学**をダイレクトに反映する
    グラニュラー」=カードの語彙からAIが切り取り・配置を決めてループを組む(音をAIに聞かせられない分を言葉で補う)。その下地として:
    オーディオカードは**カード**(再生・ループ・音量・残響+**語彙メモ**`s.memo`)と**スフィア**(`s.view: 'sphere'`、小さな球で再生バーが
    12時から時計回り。画面を煩雑にしないため)を切り替える(カードの◯/▭、エリアの見出しで全部)。**波形の上のドラッグで鳴らす範囲を切り取る**
    (`s.clipStart/clipEnd`、秒。端をつかむと片側。ダブルクリック/✕で外す)。フリーのループ・タイムラインの発音・再生位置は切り取った範囲だけ。
    タイムラインの「音の長さの光る帯」は廃止。**どのフォルダの枠の外に出したカードも鳴らない**(`folderId: null`、出どころは`sourceFolderId`)。
    ループの長さは −/+(押し続け・Shiftで1秒)・数字のドラッグ/ホイール/↑↓/ダブルクリックで入力・½・×2・「音に合わせる」。▶再生/■ は見出し2段目の左端。
    波形・ループの数字のように、部品自身がドラッグを使う要素には`.no-card-drag`を付ける(js/canvas.js がカードの移動・パンを始めない)
  - **チェーン(3つ目のモード、2026-09-29、ユーザー要望「アステリズムで繋いだカードが順次再生するループ」)**: オーディオカードにASTRを出し、
    線(`state.premix.connections`)の**向き**(`cardIdA`=引き始め → `cardIdB`=離したカード)に順に鳴らす。前の音(切り取った範囲)が鳴り終わった
    瞬間に次を鳴らす(隙間なし)。**分かれ道は毎回ランダムに1本**(ユーザー判断)。たどるのは同じエリアのカードだけ。
    **アステリズムベルト(同日、ユーザー要望「2つのカードをつなげた時点で反復ループ。複数のベルトを同時再生」)**: 線でつながったまとまり(向きは
    問わない)=1本のベルト。**行き止まりで流し始めたカードへ戻る**ので、2枚つないだだけで反復ループになる(輪を作らなくてよい)。チェーンのエリアで
    線を引いた時点でそのベルトが鳴り始める。ベルトごとに流れ(歩き手)を1つ持ち、複数のベルトが同時に鳴る。カードの▶/■はそのベルトだけ、見出しの

    発音はタイムラインと
    同じ先読みの予約(`voiceAt()`を共用)。プレミックスの線は流れる点線(向きが見える)で、流れが通った線を光らせる。**線のレイヤーはフォルダの上・

## アステリズムの線の種類: リンクとチェイン(プレミックス、2026-10-01)

- 線にカーソルを合わせると光り(js/app.js の`redrawAsterismLines`。線の当たり判定の`pointerenter`)、押すと画面の`onLineTap`に任せる
  (無い画面は今までどおり削除の確認)。プレミックスでは、浮いたメニューで「**リンク**」「**チェイン**」「**削除**」を選ぶ
- `connection.mode = 'link' | 'chain'`。無ければ chain(以前からの線)。ASTRで新しく引いた線は chain。見た目はリンク=まっすぐな水色の線、
  チェイン=流れる琥珀の点線(向きが見える)
- **鳴らし方は「流れ(歩き手)」にまとめた**(js/screens/premix.js のチェーンの節): 流れがカードを鳴らす時、**そのカードとリンクでつながったカードも同じ時刻に
  鳴らし**、一番長い音が鳴り終わった時に**チェインの線だけをたどって**次へ進む。行き止まりでは流し始めたカードへ戻る。
  リンクだけのまとまりは、全部が鳴り終わってから揃って頭に戻るループになる
- **フリーのエリアでも、線でつながったカードの▶はこの流れで鳴らす**(以前はチェーンのエリアだけ)。ループを外したカードから鳴らした時は1周で止める。
  チェーンのエリアのベルトは今までどおり(線を引くと鳴り始め、繰り返す)。タイムラインのエリアでは線は鳴らし方に使わない
- 確認: リンク(元5.6秒・応答6.6秒)が同じ時刻に鳴り、6.68秒で揃って頭に戻ること、リンクとチェインを混ぜると「元と厳格対位法(リンク)が同時 →
  元が鳴り終わった所でカノン(チェイン)→ 頭へ」となること、メニューでの切り替え・削除を、実際のマウス操作で確かめた

## ミュートとソロ(プレミックスのオーディオカード、2026-10-01)

- ユーザー要望「MIDIカードにミュート、ソロ機能」。MIDIに限らず、オーディオカード全部の ▶・ループの並びに **M**(ミュート、赤)と **S**(ソロ、黄)。
  `s.mute` / `s.solo` に保存
- **ソロはエリアごと**: そのエリアに1枚でもソロのカードがあれば、ソロのカードだけが鳴る。ミュートはソロより強い。鳴らないカードは暗くする
- カードの音量のゲインに掛ける(`cardGain()`=音量 × `audibleOf()`)。残響への送りはゲインの後ろなので一緒に消える。フリーの再生・流れ(リンク/チェイン)・
  タイムラインのどれでも効き、鳴っている途中でも切り替えられる(`applyMuteSolo()`)。カードを別のエリアへ動かした・外した時も効き方を直す

ユーザー要望「プレミックスのボトムツールに『音色』を置いてグラスモーフィズムで、ソウルと LYRA Host で挟撃解析中のプラグインの音色語彙の検索窓をフローティングに。
左で音色検索、右で LYRA Host を見比べながら使いたい」。
- 道具バーの「**音色**」(どのプレミックスのプリセットにもある道具)で、画面の左に縦長のグラスモーフィズムの窓。見出しで動かし、右下の角で大きさを変える
  (動かした・変えた時だけ `lyra.timbreWin` に覚える。開いた直後の既定の大きさでは固めない)。ネビュラ・プラネテスのアルバムと Pixabay の窓と同じ場所なので、
  どれかを開くと他を閉じる
- 開いた時に LYRA Host につながっていれば、ホストの小窓を `floatWindow('top-right')` で右へ寄せる(ホストが覚えた位置が優先)。見出しの「Host ▶」でも
  (つながっていなければ起動してつなぐ)
- プラグインのソウルを選び(目録・対応表のあるものが先。`lyra.timbreSoul`)、1つの検索欄で4つのタブを引く: **プリセット**(目録の言葉の絞り込み+
  「Geminiに探してもらう」1回。選んだものは候補リストに残る)/ **パラメータ**(ソウルの効果・意図と VST の対応。確認済み=実線、未確認=点線。
  VSTにだけあるパラメータも出す。「ホストの今の値」で表示中の結んだ行の値を `getParams` で読む)/ **候補**(`soul.presetPicks`)/ **記録**(`soul.patches`)
- 読むだけ(ソウルは書き換えない)。窓の中のキー入力・ポインター・ホイールはプレミックスへ届かせない
- 確認: ヘッドレスEdgeで、スタブの状態(目録3件・対応表・候補・記録)で4つのタブの表示、言葉の絞り込み、Gemini(模擬)の選択(目録に無い番号が弾かれ、
  候補リストに残る)を確かめた。**本物の目録・本物のホストでの「今の値」・小窓の並びはまだ**
