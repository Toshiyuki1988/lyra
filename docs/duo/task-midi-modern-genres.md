# 音楽史マップの拡張: 最近のジャンル(〇〇コアなど)の仕分け案

2026-11-08、ユーザー依頼「最近の〇〇コアなんかもすべて含めると膨大になるか」→「(MIDI で区別できるものに)仕分けた案をお願い」。
**これは仕分け案(選ぶための一覧)で、まだ何も作っていない**。ユーザーが選んだものだけを、波に分けて作る(`task-midi-history-map.md` と同じ作り方: プリセット・子どもの解説・参照曲・お手本の3点。ビートはビート帳へ)。

## 進め方
- B(重い: Claude Code が計画)。ビート帳へ足す分と、プリセットを足す分は、選ばれたら1波5〜10件の「既存の仕組みの延長」なので A として Codex に回せる。生成器を足すものは B のまま
- **【推測】の印は、Claude Code の記憶による分類**。ジャンルの定義・参照曲・年代は、作る前に監修(`task-midi-history-review.md`)で確かめる
- 作り方の方針: 似たものは1つのモデルにまとめ、違いはビート帳の `variation` やプリセットの `guide`(層の組み方)に逃がす。件数を増やすより、聴いて違いが分かるものだけを足す

## 仕分けの基準
- **A ビート帳に足す**: ドラムのリズムの型で区別できる(キックの置き方・ブレイクの刻み・拍の割り方・テンポ帯)
- **B プリセットを足す**: 和声・旋律の型・伴奏型・形式・編成の使い方で区別できる。今ある生成器の組み合わせで作れる
- **C 生成器・仕組みが要る**: 今の生成器では作れない
- **D モデルにしない**: 音色・ミックス・歌声・見た目・文化の違いが中心で、MIDI の並びでは区別できない(音源・VST 側の話)

## C. 生成器・仕組みが要る(約8件)
| id 案 | 名前 | 要るもの |
|---|---|---|
| nightcore | ナイトコア | 元のMIDIのテンポと音高を上げる変換(「伸ばす」の仲間。生成器でなく変換の操作) |
| glitchcore | グリッチコア | 音の断片のスタッター・逆回し・音高のずらしを連続で(`tapecut` の応用でできる可能性) |

## D. モデルにしない(音色・文化が中心)
mallsoft・dreamcore・weirdcore・traumacore・liminalcore・cottagecore・goblincore などの視覚・文化の〇〇コア、サイバーグラインド等の音色・ミックスで区別されるもの、
vaporwave の派生(`vaporwave` で足りる)、歌声・歌詞・ファッションで区別されるジャンル。

## ユーザーに確かめること
1. **どの区分から作るか**(おすすめ: A のビート帳 → B のうち 2020年代に聴かれる音楽 → 残り)
2. **件数を絞るか**(例: A と B から各15件ずつ、計30件だけ)
3. **plunderphonics・mashup は作らない方針でよいか**(既存の曲を切り貼りする性質上、著作権ゲートに関わる)
4. 地図の時代区分に、**「現代(2000年代〜)」を足すか**(今は電子音楽・ポピュラー・ヒップホップに散らばっている)
