- 無い。近いものは、モデルのピッカー(`js/midi/compose.js` の `pickModel()`、304行あたり)と、その中の子どもの解説の吹き出し
  (`bindKidsPopups()`、146行)・お手本の窓(`openDemo()`、203行)。地図ではこの2つをそのまま使い回す

## 4. やること・受け入れ条件
### やること
1. 新しいファイル `js/midi/historymap.js`(`(function () { ... })();` で包む)。`window.LyraHistoryMap = { open(options) }` を出す
   - `open({ onPick })`: 地図の窓を開く。地図の行でモデルを選んだら `onPick(id)` を呼んで窓を閉じる
   - `models/history-map.json` は、初めて開いた時に `fetch()` で読み、以後は覚えておく。読めなかったら窓の中に「地図を読み込めませんでした」と出す
2. 見た目と中身は試作(`mockups/midi-history-map-mockup.html`)と同じにする: 時代ごとの見出し(年代・「作成済み/全件」)、1行=1モデル
   (★/・、名前、説明、印)、上に件数のまとめ、絞り込み(すべて・作成済み・未作成・解説が無い・お手本が無い)と検索欄、行を押すと詳しく開く。
   色はアプリの今の窓(`.modal`)に合わせてよい
3. `pickModel()` の窓の見出しの横に「音楽史マップ」のボタンを足す。押すと、ピッカーの上に地図の窓を重ねて開く
   - 地図で選んだら、ピッカーで選んだ時と同じ `finish(id)` を通す(前回のモデルの保存も同じ)
   - 地図を閉じたら、ピッカーに戻る(ピッカーは閉じない)
4. 地図の行で選べるのは「ピッカーに出るプリセット」(`LyraPresets.byId(id)` があり、`hidden` でないもの)だけ。それ以外は選べない行にして、
   詳しく開いた所に理由を1行出す:
   - 未作成 → 「まだ作っていません(作るのに要るもの: P/G/M)」
   - `kind` が `beat` → 「ビート帳の型です(MIDI の『ビート』から使えます)」
   - `kind` が `response` / `extend`、または `hidden` のプリセット → 「プレミックスの MIDI カードの『応答』『展開』から使います」
5. 選べる行には、ピッカーと同じ ▶(お手本)と子どものアイコンを付ける。`openDemo()`・`bindKidsPopups()` を compose.js から使えるようにして
   (今は compose.js の中だけの関数。`window.LyraCompose` などに足すか、historymap.js に引数で渡す。どちらでもよい)、アイコンを押してもモデルは選ばない
6. 窓の閉じ方: ✕ のボタンと、背景のタップ(`attachBackgroundTapToClose()`)。地図の窓の背景タップで、下のピッカーまで閉じないこと
7. CSS は `css/style.css` に足す(`.history-map` で始まるクラス名)。`index.html` に `js/midi/historymap.js` のタグを compose.js の前に足し、
   **編集した JS・CSS の `?v=` をすべて更新する**
8. `docs/midi.md` の「将来のMIDI生成モデルの候補」の節に、地図の画面の入口と動きを、日付つきで2〜3行追記する

### 受け入れ条件
- [ ] ピッカーの「音楽史マップ」から地図が開き、212件が16の時代の見出しの下に、JSON の順で並ぶ
- [ ] 件数のまとめが「全 212 件 / 作成済み 70 件(解説あり 11・お手本あり 24)/ 未作成 142 件」(2026-11-06 時点。モデルを足すと自動で変わる)
- [ ] 選べる行(例: バッハ風・確率過程モデル)を押して「このモデルで作る」系の操作をすると、ピッカーで選んだ時と同じようにそのモデルで先へ進む。次にピッカーを開くと「前回」の印がそのモデルに付く
- [ ] 選べない行(例: フーガ=未作成、ハウス=ビート帳、ポリコード=応答)は選べず、理由が出る
- [ ] 地図の ▶ でお手本の窓が開いて鳴り、子どものアイコンで解説の吹き出しが出る。どちらを押してもモデルは選ばれない
- [ ] 絞り込みの5つのボタンと検索欄が試作と同じ結果になる
- [ ] 地図を ✕ / 背景のタップで閉じるとピッカーに戻る。もう一度ピッカーの背景をタップするとピッカーが閉じる
- [ ] 操作の衝突: 地図の中のスクロール(ホイール・タッチ)で窓が閉じない・行が選ばれない。スマホ幅(390px)で、行の印が説明に重ならず、横にはみ出さない
- [ ] 保存して読み込み直した後: この作業は保存データを変えない(前回のモデルの `localStorage` だけ)。読み込み直してもピッカー・地図が同じに動く
- [ ] コンソールにエラーが出ない

#### 選ぶ操作の決め方(【推測】Codex が決めてよい)
行を1回押すと詳しく開く(試作の動き)。選べる行は、詳しく開いた所に「このモデルで作る」のボタンを出し、それを押すと選ぶ。
行を押しただけで選ぶと、詳しく見たいだけの時に誤って進むため
