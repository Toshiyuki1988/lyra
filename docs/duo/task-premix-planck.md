## 用語
- **プランク**: エリアの中に置く新しいカード(`type: 'planck'`)。正方形の視野の中で、左から右へプレイヘッドが流れる
- **波形**: プランクに入ったオーディオカード。カードの見た目は消え、鳴らす範囲の波形だけになる
- **段**: プランクの中の横の帯(トラック)。1〜10段
- **照準(HUD)**: プランクの右下の角に半分はみ出して置く円。左右のドラッグで長さ、上下のドラッグで段の数

## 対象範囲

### 段階1: プランク本体
1. **道具バーに「プランク」**: 押すとアクティブなエリアの中(見えている範囲の中央付近)に置く。エリアが無ければ `ensureArea()` と同じ考えで作る。
   COSMIC 固有の道具ではなく、どのプリセットでも出す
2. **プランクの見た目**(モックどおり):
   - 視野は正方形(モックは 440px)。左に段の見出しの列(段n・M・S)、上に PLANCK・▶/■・読み出し(長さ×段数、選んだ波形の名前・範囲・音量)
   - 中と外の境界はマスクでぼかす。視野の照明(中央が明るい)・漂う塵・青い光のにじみ
   - 時間のグリッドは長さに合わせて細かくなる(0.1ms〜10s の刻み)。終わりの線(橙)。段の帯と区切り線
   - **見えているものがすべて**: 倍率の変更・横スクロールは無い。長さ全体が視野の幅、段の全部が視野の高さ
3. **照準の HUD**: 左右のドラッグで長さ(60px で2倍。0.1秒以上は 0.01秒に丸める)、上へのドラッグで段を増やす(22px で1段)。
   範囲は 長さ 5ms〜60s、段 1〜10。中央の点がドラッグの向きへずれ、離すと戻る。外周の目盛りが長さで回り、下の弧の点が段の数
   - 長さは**中のいちばん長い波形(鳴らす範囲の長さ)より短くできない**。縮めると、はみ出しそうな波形は左へ寄せて収める
   - 段は**波形が置いてある段より下は消せない**
4. **オーディオカードを入れる**: カードをプランクの視野の上へ運ぶと、入る段が光り、本当の長さの点線の枠と「切り取った範囲/全体 n秒」が出る。
   落とすとポインターの位置(グリッドにそろえる)が鳴り始め、指した段に入る。**範囲がプランクより長ければ、プランクの長さを広げて入れる**
   - **長さの上限は60秒**(2026-10-07、ユーザー決定)。鳴らす範囲が60秒より長いカードは、**カードの再生範囲の頭(`clipStart`、無ければ0秒)から60秒**に
     `clipEnd` を縮めて入れる。確認のダイアログは出さない。落とす前の点線の枠の所に「頭から60秒を入れます(元は n分n秒)」と出し、入れた後もステータスに出す。
     縮めたのは範囲だけなので、プランクの中で端を広げ直す(60秒まで)・カードに戻してから範囲を外すことができる
   - 変身のアニメーション(モックの `morph()`): カードの殻が溶け、カードの波形の窓だけが残って切り取った範囲へ縮まり、本当の長さ・段の高さへ飛び込む。
     スフィアは球がつぶれて横に伸びる。着いた所で一瞬光る
5. **プランクの中の波形の操作**:
   - 中のドラッグ = 左右で時間(グリッドにそろえる。Alt でそろえない)、上下で段。波形は必ず丸ごと中に収まる
   - **左右の端のドラッグ = 鳴らす範囲**(`clipStart/clipEnd` をそのまま書き換える)。左端を削ると、中身の位置はそのままで鳴り始めが後ろへずれる。
     ファイルの外・プランクの外へは出ない。範囲が全体に戻ったら `clipStart/clipEnd` を消す。ドラッグ中だけ範囲の外の残りを薄く見せる
   - **上の線のドラッグ = 音量**(`volume` 0〜100 をそのまま書き換える)。波形の振れ幅も一緒に変わる。鳴らしながら変えても効く
   - ラベル: 名前・音量・残響(0でなければ)
   - キー(波形を選んでいる時): ←→ グリッド1つ(Shift ×10、Alt 1ms)、↑↓ 段、Delete/Backspace = カードに戻す
   - 【推測】範囲の端もキーで細かく動かせる: 最後につかんだ端(左/右)を Ctrl+←→ でグリッド1つ、Ctrl+Alt+←→ で 1ms
     (長いプランクでは 1px が粗く、ドラッグだけでは細かく切れないため)
5b. **長いプランクでも崩れないように**(10分の曲の検討から):
   - **細すぎる波形にも最低3pxの幅と当たり判定**を持たせる(60秒の中の50msは0.3pxになり、見えず・つかめなくなる。見えているものがすべて、を守る)
   - グリッドの刻みを 30秒・1分まで足す。長さ・目盛りは60秒以上を「1:00」の形で出す(上限が60秒なので最大「1:00」)
   - 変身のアニメーションは、**切り取った範囲だけを描き直した絵**を使う(長いファイルの一部を切ったカードで、全体の絵を引き伸ばすとぼやけた塊になる)
   - プランクの中の描画は、前もって作った**倍率ごとのピーク(間引きの波形)**から描く。毎フレーム元のサンプルをなめない。
     倍率が高く1pxあたりのサンプルが少ない時だけ、元のサンプルで本当の波の形を描く
   - 解凍した音のメモリ(ステレオ48kHzで1分あたり約23MB)は今のカードと同じで、プランクで増やさない(同じ AudioBuffer を使う)
6. **カードに戻す**: 外へドラッグ(プランクの枠から30px以上出たら、カードに戻ってそのまま運ばれる)か Delete。逆の変身。
   範囲・音量は持ち帰る(カードの切り取り・音量のつまみに出る)。元の見た目(カード/スフィア)に戻る
7. **段ごとのミュート/ソロ**: ソロの段があればソロの段だけ、無ければミュートしていない段が鳴る。Shift+S でほかのソロを外してその段だけ。
   鳴らしながら切り替えても、その場で聞こえ方が変わる。聞こえない段は帯も波形も暗くする
8. **再生**:
   - プランクの中の時間はプレイヘッドだけ。プランクの長さで頭に戻る。各波形は、プレイヘッドが左端に触れた時に鳴らす範囲を1回鳴らす
   - 音の通り道は今のオーディオカードと同じ(`voiceAt()` → `stripOf(s)`=ネビュラ・PLANETES の通り道 → エリアのバス、残響の送り)。
     音量 = `volumeGain(volume)` × 段が聞こえるか
   - **長さを変えた時に、予約済みの音を二重にしない**(モックで実際に起きた不具合。予約の記録を消して基準を置き直すだけだと、
     先読みで予約済みの音をもう一度予約して音量が倍になる。モックの `setInterval` の「長さが変わった」の処理と同じく、
     まだ鳴り始めていない予約は取り消し、今の周ですでに鳴った音は「鳴らした」と覚え直す)
   - アクティブでないエリアのプランクは、今のカードと同じく聞こえない(バスの音量0)
9. **チェーンの中の駒として**: プランクにも ASTR の線をつなげる。流れ(歩き手)がプランクに来たら、プランクを頭から終わりまで**1回**鳴らし、
   終わった瞬間に次へ進む(行き止まり・分かれ道の決まりは今のカードと同じ)。リンクの線でつながったカードとは同時に鳴る。
   どこにもつないでいないプランクは、▶ でそれだけを繰り返し鳴らす。エリアの見出しの ▶ は、ベルトに加えて、線の無いプランクも鳴らす
10. **保存と読み込み**: プランクと中の波形の状態が Drive のプレミックスのデータに残り、開き直すと同じ状態になる。MIDIのカード(`midiRef/midiInline`)・
    単体のオーディオ(`single`)も入れられ、開き直した時に音を作り直す・読み直すのは今と同じ
11. **周りの機能との関係**:
    - プランクのカードの編集ガイド: Delete・ASTR・ピン留め。**プランクを外す時、中の波形はカードに戻してエリアに残す**(消さない)
    - 矩形選択の「アプリからリジェクト」: プランクは囲みに全部入った時だけ選ぶ。外すと中の波形はカードに戻してエリアに残す。ピン留めした波形を抱えたプランクはリジェクトしない
    - プランクをドラッグすると、中の波形も一緒に動く(データ上は位置を持たないので、プランクの位置に従う)。別のエリアへ動かすと、中の音もそのエリアのバスへつなぎ替える
    - ネビュラ・PLANETES: 中の波形は**プランクの中心を自分の位置として**影響を受ける(ユーザーに確かめること2)
    - Shift+D(複製)・語彙(Gemini)・応答・伸ばす・ホストはプランクの中の波形には出さない(カードに戻せば使える)

### 段階2: モードの統一と移行
1. エリアの見出しのフリー/タイムライン/チェーンの切り替えを無くし、すべてチェーンとして扱う。ループの長さの操作(−/+・½・×2・音に合わせる)も無くす
2. **移行**(プレミックスのデータを読み込んだ時に1回):
   - `mode: 'timeline'` のエリア → エリアの中にプランクを1つ作り、中のカードを `tlStart` の時刻のまま波形として入れる。長さ = `loopSec`(既定8秒)。
     段は重ならないように上から順に詰める(10段を超えるなら、プランクを2つに分ける)
   - タイムラインでループの終わりを超えていた音は、今まではループの終わりで切れていた。**同じ聞こえ方を保つため、`clipEnd` をループの終わりまでに縮める**(【推測】ユーザーに確かめること5)
   - `mode: 'free'`(または無し)のエリア → `mode: 'chain'`。線の無いカードは ▶ でそれだけが繰り返し鳴る(今のチェーンと同じ)
   - **戻せるように、移行前の値を残す**: エリアに `legacy: { mode, loopSec }`、カードの `tlStart` は消さずに残す
3. タイムライン・フリーにしか使わなくなった処理を整理する(`isTimeline`・`scheduleTimeline`・`loopSec`・`tlStart`・`setFreeLoop`・カードのループのボタン・
   `snapToGrid` など。`isTimeline` の参照は今17か所)。`voiceAt()` は残す。語彙(エリア)の録る長さの決め方、Shift+D の置き場所の決め方も直す
4. `docs/premix.md` の「フリー/タイムライン」の節に、統一と移行の記録を足す(消さずに、置き換えたことを書く)

## 設計・制約
- **データ**(【推測】の形。Codex は実装前に既存のデータとの食い違いを確かめる):
  - プランク: `{ id, type: 'planck', folderId(いるエリア), x, y, len(秒), lanes: [{ id, mute, solo }], pinned?, createdAt }`。大きさは固定なので width/height は持たない(持つなら固定値)

  カードをプランクへ落とす判定は `onCardMoved`(`dropSound()`)で、エリアの判定より先にプランクの視野を見る
