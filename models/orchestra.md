# 管弦楽の作曲を「名曲の水準」へ近づける理論(構想)

2026-10-08、ユーザー「面白いけど動き15種を入れ替えてるだけだな。前回作ったオーケストラモックアップも同じ感じだった。
これをどこまでクラシックの名曲レベルまで上げられるか、その理論構築が重要だ」。
対象は、試作 `mockups/mickey-mockup.html`(ミッキーマウシング)と `mockups/symphony-mockup.html`(交響エンジン)。どちらも git 管理外。
**まだ実装しない**。この文書は、層を1つずつ試作して耳で確かめる時の設計の正本。

関係する資料: `midi-generation-models-and-style-architecture.md` の「緊張曲線モデル」「動機変容モデル」(この文書はその2つをまとめて具体化する)、
`gakuten.md`(和音の積み方・声部進行の今の実装)、AGENTS.md の「Gemini に創造させる時は2段階に分ける」。

---

## 1. 診断: なぜ「型の入れ替え」に聞こえるか

部品の並べ替えはできているが、**部品どうしを結ぶ構造**が無い。

| 観点 | 今の試作 | 名曲にあるもの |
|---|---|---|
| 素材 | 動きごとに別々の書法(15種の型)。交響エンジンも区間ごとの型 | すべてが1〜2個の動機から生まれる。事件の音も、主題の変形 |
| 和声 | I–vi–IV–V の循環、区間ごとの決まった和音 | 機能の文法(安定 → 準備 → 緊張 → 解決)と、曲全体の調の計画。大事な瞬間は終止に来る |
| 句 | 動きの長さで切れる | 4・8小節の文や楽節。聴き手が次を予測できるから、裏切りが効く |
| 声部 | 和音を積むだけ | 各声部のなめらかな進行・対旋律・内声の動き |
| 緊張 | 動きの激しさで局所的に上下 | 曲全体の緊張の曲線(頂点は1つ。準備して、頂点の後は解く) |
| 管弦楽 | 楽器を割り当てる | 層の役割(主旋律・対旋律・和声の地・低音・刻み・色)、音域の配置、重ね方、楽器の足し引きで作る強弱 |
| 時間(劇伴) | ヒットに音を置くだけ | テンポの地図を逆算し、強拍・終止をヒットに合わせる。音楽が先に準備し、ヒットで着地する |

名曲は「**統一**(同じ素材)× **変化**(その変形)」が「**予測**(文法)× **裏切り**(意図した逸脱)」の上で釣り合っている。
今の試作は変化はあるが、統一と文法が無い。

## 2. 骨組み: 5つの層

音楽理論の主な流れを、生成の層に置き換える。上の層が下の層の枠を決める。

| 層 | 決めること | 元にする理論 | 誰が |
|---|---|---|---|
| A. 背景 | 形式(区間と機能)・調の計画・緊張の曲線・頂点 | シェンカーの背景層、ソナタ・ロンド等の形式、緊張曲線 | **Gemini(言葉の発想)**+エンジンの整え |
| B. 中景 | 句(文・楽節)・和声進行・終止・テンポの地図 | カプランの形式機能、機能和声、声部進行 | エンジンの規則 |
| C. 前景 | 動機とその変形で全部の音を作る | シェーンベルクの発展的変奏・基本形態 | エンジンの規則(動機の発想は Gemini) |
| D. 管弦楽 | 層の役割・音域の配置・重ね方・楽器の足し引き | 管弦楽法(リムスキー=コルサコフ、アドラー) | エンジンの規則(色の方針は Gemini) |
| E. 批評家 | 候補を測って選ぶ | 予測と驚き(ヒューロン)、指標 | エンジンの計算 |

**分担の決まり**: Gemini(軽量版)は言葉の発想が得意で、対位法・声部進行のような正確さの要る作業は苦手。
だから「何を・なぜ」は Gemini、「どう正しく書くか」はエンジンの規則にする(AGENTS.md の2段階の決まりと同じ考え)。

### A. 背景の層(曲全体の設計)
- **形式**: 区間ごとに機能を持たせる(提示・推移・展開・頂点・再現・終結)。劇伴では、シナリオの事件をこの機能に対応させる
  (例: 導入の歩み=提示、事件の連鎖=展開、最大の事件=頂点、落ち着き=終結)
- **調の計画**: 主調から近い調へ出て、頂点の前に遠くへ行き、主調へ帰る。調の距離は5度圏で測る。再現・終結は主調
- **緊張の曲線**: 0〜1の曲線を先に決める。**頂点は1つ**(全体の 60〜80% の位置が多い)。それより前の小さな山は頂点より低くする。
  頂点の後は短く解く。下の層は、この曲線から音数・音域・和声の不協和・楽器の数を逆算する
- Gemini には言葉で「場面の流れと、どこが頂点か、どこで何の調の色にしたいか」を考えさせる(1段目)。エンジンは数値に直して整える

### B. 中景の層(句・和声・時間)
- **句の型**: 文(sentence: 基本の考え2小節+その繰り返し2小節 → 展開4小節(断片化・和声のリズムの加速)→ 終止)と、
  楽節(period: 前楽節が半終止、後楽節が完全終止)。区間の機能に合う型を選ぶ(提示=楽節、展開=文の展開部を伸ばす、など)
- **和声の文法**: T(主)→ PD(下属・準備)→ D(属)→ T の流れを基本に、句の終わりに終止を置く。
  和声のリズム(和音が変わる速さ)は、緊張とともに速くする。頂点の前は属音の保続音で引っぱる
- **声部進行**: 4声体の規則(共通音は残す、ほかは最短距離、並行5度・8度を避ける、導音は上へ)で和音をつなぐ。
  今の `gakuten.md` の `chooseVoicing()` を土台にできる
- **テンポの地図(劇伴)**: ヒット(事件の瞬間)を、強拍か終止の着地に合わせる。区間ごとにテンポをわずかに変える(±8%程度)か、
  小節を足し引きして、ヒットの時刻 = 小節の頭 になるよう逆算する(映画音楽の作曲で実際に使う方法)。
  合わせきれない小さな動きだけ、拍の途中の装飾(グリッサンド・打楽器)で拾う

### C. 前景の層(動機から全部を作る)
- **動機**: 主人公(または主題)ごとに1つ。3〜8音。音程の形とリズムの形を別々に持つ(片方だけ使う変形ができるように)
- **変形の操作**: 反復・反復進行(高さをずらす)・反行(上下を逆に)・逆行・拡大(長く)・縮小(短く)・断片化(頭だけ)・
  音程の拡大/縮小・リズムだけ残す・音高だけ残す・液化(特徴を少しずつ失う)
- **劇伴での対応(例)**: 歩く=原形、忍び足=原形のリズムだけを小さく、走る=縮小して音階につなぐ、落ちる=反行を半音階化、
  ぶつかる=動機の音程を同時に重ねた塊、驚く=動機の頭の音程を拡大して金管で、眠る=拡大して子守歌の和声に、
  **頂点=原形を全奏で**。これで「15種の型」ではなく「1つの主題がドラマの中で変身していく」音楽になる
- **変形の文法**: 変形は前の変形から少しずつ離れる(いきなり遠くへ行かない)。再現で原形に戻ると、統一が聞こえる
- 動機は Gemini に発想させてよい(2段階の1段目)。引用でないかの反芻を必ず通す(AGENTS.md の決まり)

### D. 管弦楽の層(質感)
- **層の役割**: 主旋律・対旋律・和声の地・低音・刻み(リズムの層)・色(装飾)。同時に聞こえる主役は1つ(多くて2つ)
- **音域の配置**: 倍音列に沿って、低い所は広く(オクターブ・5度)、高い所は狭く。低音域で3度を重ねない
- **重ね方**: 主旋律は同じ音色の重ね(ユニゾン)か、オクターブの重ねで強める。違う族を重ねると色が混ざる
  (弦+木管=やわらかく、弦+金管=輝く)。頂点では全族を重ねる
- **強弱は楽器の足し引きで**: 緊張の曲線に合わせて層を足していく(クレッシェンドを、1人の音量でなく人数で作る)。
  頂点の直前に一度引く(息をのむ間)と、頂点が大きく聞こえる
- **音色の名札**: 主人公の楽器を固定し、変身の時だけ色を変える(同じ動機を別の楽器へ渡すこと自体が展開になる)

### E. 批評家(候補を測って選ぶ)
同じ設計図から、乱数を変えて数個の候補を作り、指標で点をつけて良いものを残す。エンジン側の計算なので、Gemini の回数は増えない。
指標の案:
- **動機の占有率**: 主旋律・対旋律の音のうち、動機(とその変形)から生まれた音の割合。高いほど統一
- **新しさの比**: 直前の区間と同じ形の繰り返しの割合。高すぎても低すぎても減点(予測と驚きの釣り合い)
- **和声の文法**: 終止の位置が句の終わりに来ているか、和声のリズムが緊張とともに速くなっているか
- **声部進行**: 声部の跳躍の平均、並行5度・8度の数
- **緊張曲線との一致**: 実際の音数・音域・不協和・楽器数から計算した緊張と、背景の層の曲線との差
- **ヒットの精度(劇伴)**: 事件の時刻と、強拍・終止・装飾の時刻の差
- **音域の配置**: 低音域の密集、族ごとの音量の釣り合い

## 3. 見通し

「名曲そのもの」は目標にしない。目指すのは **職人として正しく書けていて(文法・声部進行・管弦楽法)、そのうえで意図した驚きがある** 所まで。
そこまでは規則と批評家でかなり近づける。そこから先の一回きりの霊感は、Gemini の発想とユーザーの選択(★)が担う。

## 4. 進め方(層を1つずつ試作して耳で確かめる)

いきなり全部は作らない。今のミッキーマウシングの試作に、1層ずつ足して聴き比べる。
1. **C. 前景**: 1つの動機から全部の動きを作る(型の入れ替えに聞こえなくなるか)
2. **B. 中景**: 句と和声の文法・声部進行・テンポの地図(ヒットが音楽の着地に聞こえるか)
3. **A. 背景**: 緊張の曲線と頂点、調の計画(1曲としての山が聞こえるか)
4. **D. 管弦楽**: 層の役割と足し引き(厚みと色の変化)
5. **E. 批評家**: 候補を作って選ぶ(指標と耳の評価が合うか)

各段階で、前の段階との聴き比べを試作のページに残す。うまくいった層から、交響エンジンにも同じ層を移す。
本体(`js/midi/`)へ入れるのは、試作で耳の確認が取れてから(新しいモデルとして。プリセット・子どもの解説・お手本も1つずつ)。
